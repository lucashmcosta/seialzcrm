# Módulo: Settings

Rotas aninhadas em `/settings/*` com `SettingsLayout` (breadcrumbs, sem headers próprios — memory `architecture/settings-nested-routes-and-breadcrumbs`).

Sub-áreas:

| Sub-rota | Propósito |
|---|---|
| `general` | Config geral da org |
| `theme` | Preset de tema (memory `seialz-theme-persistence`) |
| `users` | Usuários e vínculos |
| `permissions` | Perfis de permissão |
| `billing` | Plano/assinatura |
| `pipeline` | Etapas de pipeline |
| `duplicates` | Regras de duplicidade |
| `custom-fields` | Definição de campos |
| `tags` | Tags e cores |
| `documents` | Tipos de documento |
| `integrations` | Integrações da org |
| `customer-service` | SLA / atendimento |
| `whatsapp-templates` | Templates (admin only) |
| `whatsapp-snippets` | Snippets internos |
| `ai-agent` | Agente IA |
| `ai-providers` | BYOK |
| `intelligence` | Intelligence |
| `api-webhooks` | Webhooks genéricos |
| `products` | Catálogo |
| `knowledge-base` / `edit-kb` | KB |
| `audit-logs` | Logs |
| `round-robin` | Roteamento |
| `trash` | Lixeira |

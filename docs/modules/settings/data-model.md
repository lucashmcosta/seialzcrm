# Modelo de dados — Settings

Settings não tem tabela própria; agrupa configurações espalhadas:

| Área | Tabelas |
|---|---|
| Users | `users`, `user_organizations`, `invitations`, `user_sessions`, `team_memberships`, `permission_profiles` |
| Billing | `plans`, `subscriptions`, `coupons`, `coupon_redemptions` |
| Pipeline | `pipeline_stages` |
| Custom fields | `custom_field_definitions`, `custom_field_values` |
| Tags | `tags`, `tag_assignments` |
| Documents | `document_types`, `document_submissions` |
| Integrations | `organization_integrations`, `admin_integrations`, `integration_feature_flags`, `integrations` |
| Customer service | `support_categories`, `support_sla_configs`, `escalation_targets` |
| Templates | `whatsapp_templates`, `whatsapp_template_actions` |
| Snippets | `message_snippets` |
| Round-robin | `thread_routing_rules` |
| Webhooks | `webhook_field_mappings` |
